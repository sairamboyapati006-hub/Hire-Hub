HireHub - Job Portal

HireHub is a simple job portal project built using Python, FastAPI, MySQL, HTML, CSS and JavaScript.

Features

- User registration and login
- View available jobs
- Recruiters can post jobs
- Job seekers can apply for jobs
- View submitted applications

Technologies

- Python
- FastAPI
- MySQL
- HTML, CSS, JavaScript

How to Run

Install the required packages:

pip install -r backend/requirements.txt

Configure your database settings in "backend/.env".

Run the backend from the backend folder:

python -m uvicorn main:app --reload

Open "http://127.0.0.1:8000/docs" to view the API documentation.

About

This project was built to practice Python backend development, database integration and frontend development.
